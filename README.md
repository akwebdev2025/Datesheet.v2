# PU DateSheet Simplifier — exact poster PDF template

This package contains the GitHub Pages app and the supplied Panjab University date-sheet poster artwork used as the PDF design master.

## Files
- `index.html` — website and dynamic PDF generation
- `dataset.csv` — subject dataset
- `assets/pu-template.jpg` — exact reference artwork supplied for the PDF template

## Deploy
Upload/replace all three items in the same GitHub Pages publishing root: `index.html`, `dataset.csv`, and the `assets` folder. Preserve the folder name and image filename. Commit and push the changes.

The PDF uses the supplied image as its full-page background and replaces only the example subject table with the student's selected papers. It keeps the 3:2 aspect ratio of the reference artwork; long selections continue onto additional matching pages.

This is an unofficial student utility. Verify the final schedule with Panjab University and your admit card.
